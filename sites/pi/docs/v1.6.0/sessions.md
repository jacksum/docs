# 会话与上下文 \{#sessions-and-context}

Pi 将对话保存为会话。会话的当前分支为下一次模型请求提供对话历史。通过会话命令，你可以继续工作、探索另一条分支，或减少发送给模型的对话历史。

## 继续或切换会话 \{#continue-or-switch-sessions}

除非启动时传入 `--no-session`，否则 Pi 会自动保存会话。

```bash
pi --continue
pi --resume
```

`--continue` 打开当前目录下最近的会话。`--resume` 打开会话选择器。在交互模式中，`/resume` 打开同一个选择器，`/new` 则开启新会话。

每个会话都会记录创建时的工作目录，此后不会更改。Pi 在会话的工作目录中运行；工具、`@path` 引用、项目配置和上下文文件都以该目录为准。

| 入口 | 工作目录 |
|---|---|
| `--continue` | 当前目录 |
| `--resume`、`/resume`、`--session`、`/import` | 会话的工作目录，可能与当前目录不同 |
| `--fork`，或使用 `--session` 指定另一个目录中的会话 ID 并选择派生会话 | 当前目录，在新会话中运行 |

如果会话的工作目录已不存在，例如项目文件夹已重命名，交互模式会询问如何打开会话：

- **Continue（继续）**：在当前目录中运行该会话。Pi 不会保存这个选择，下次打开该会话时会再次询问。
- **Fork（派生会话）**：与 `--fork` 一样，将会话复制到当前目录，创建一个具有新 ID 的会话。原会话保持不变。启动时创建的副本与当前目录中的其他新会话保存在同一位置；通过 `/resume` 或 `/import` 创建的副本与当前会话保存在同一位置，这与 `/new` 一致。
- **Cancel（取消）**：让当前会话保持打开；如果在启动时选择此项，则退出 Pi。

在其他模式中，Pi 会报错并退出。

使用 `/name` 或 `--name` 给会话取一个便于识别的名称。运行 `/session` 可查看当前会话的文件、ID、消息数、token 用量和费用。

在会话选择器中，你可以搜索、重命名和删除会话，也可以显示路径、更改排序或仅查看已命名的会话。按键操作见[快捷键](./keybindings.md#sessions)。

## 选择分支方式 \{#choose-how-to-branch}

Pi 以树形结构存储会话条目，因此返回较早的节点不会删除你离开的分支。

| 操作 | 结果 | 适用场景 |
|---|---|---|
| `/tree` | 在当前会话文件中切换节点 | 将相关的备选方案保留在同一个会话中 |
| `/fork` | 从较早的一条用户消息创建新会话 | 将备选方案作为独立的工作继续 |
| `/clone` | 将当前分支复制到新会话中 | 单独复制一份当前状态 |

在 `/tree` 中选择一条用户消息，会把消息文本放回编辑区。编辑后提交即可创建另一条分支。如果选择助手回复或其他条目，Pi 会从该条目之后继续，编辑区为空。

离开分支时，Pi 可以总结该分支，并把摘要附加到你切换到的分支上。这样可以保留原分支的相关工作，无需包含其中的每条消息。

会话树的存储方式和条目类型见[会话格式](./session-format.md)。

## 管理对话上下文 \{#manage-conversation-context}

模型只接收当前分支，不会收到会话文件中的其他分支。Pi 将该分支的对话历史与系统提示词、找到的上下文文件、可用工具以及已加载的技能描述合在一起。这些输入的组装方式见 [Pi 的工作原理](./how-pi-works.md#context)。

界面底部会显示当前上下文的用量。当当前上下文接近模型上限时，Pi 通常会自动压缩较早的对话历史。上下文压缩会添加摘要并保留近期消息，也不会删除原始会话条目。

运行 `/compact` 手动压缩上下文。如果希望摘要保留特定话题或决定，可以附加指令。自动压缩和保留多少对话历史可在[设置](./settings.md#compaction)中配置。

如果模型提供方不可用或无法接收摘要请求，上下文压缩可能失败。解决模型提供方的问题后，再运行 `/compact`。关闭自动压缩后仍可使用这条命令手动压缩。

有关阈值、历史记录的保留边界、分支摘要行为和扩展钩子，见[上下文压缩参考](./compaction.md)。

## 管理会话存储 \{#control-session-storage}

默认情况下，Pi 将会话保存在 `~/.pi/agent/sessions/` 下，并按工作目录分组。使用 `--session-dir`、`PI_CODING_AGENT_SESSION_DIR` 或 `sessionDir` 设置选择其他位置。命令行选项的优先级最高。

使用 `--no-session` 运行临时会话。Pi 退出后，临时会话无法恢复。

## 导出或分享会话 \{#export-or-share-a-session}

使用 `/export` 将当前会话导出为 HTML 或 JSONL。使用 `/share` 上传当前会话并获取查看链接。默认情况下，如果已配置 Radius 认证，Pi 使用 Radius 制品（artifact）；否则使用未公开列出的 GitHub Gist（secret gist），任何拿到链接的人都可以查看。将 [`sessionShareDestination`](./settings.md#sessions-and-context) 设为 `gist` 或 `radius`，可固定使用指定的目的地。

导出或分享会话前，请先检查会话内容。其中可能包含提示词、模型回复、工具参数、命令输出、文件内容和扩展消息。

## 报告缺陷 \{#report-a-bug}

运行 `/bug [description]`，为 Pi 开发者准备一份私密报告。你可以附上会话记录，也可以省略记录，或让当前模型总结问题。会话记录或生成的摘要可能含有敏感对话数据，请先检查。

报告包含环境和模型提供方的配置（不含凭据值），以及已记录的错误诊断信息。你可以通过 `radius.pi.dev` 上传报告，也可以将同一份报告导出为 zip 文件，自行检查和分享。上传不要求登录；如果已通过 Radius 认证，报告会关联到你的账号，方便开发者跟进。如果上传失败，Pi 会提供导出 zip 文件的选项。
