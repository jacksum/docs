# 译文术语

正文中的命令、配置键、枚举值、文件名、接口和代码示例保留原文。译文中第一次出现专有功能时，保留其名称；日常概念按下表统一。

| 原文 | 译法 | 用法 |
| --- | --- | --- |
| agent | 智能体 | 运行任务的主体；命令或 API 中的名称保留 |
| subagent | 子代理 | 由其他智能体创建的执行主体 |
| Agent Hub | 智能体中心 | 界面中的英文名称按原样保留 |
| model provider | 模型提供方 | 不与配置发现的提供程序混用 |
| capability provider | 能力提供程序 | 提供配置发现或功能资源的程序 |
| role | 角色 | 如模型角色；`@default`、`@smol` 等保持原样 |
| thinking level | 思考档位 | 与按请求调整的推理强度区分 |
| session | 会话 | 一次可保存和恢复的交互 |
| transcript | 会话记录 | 与终端滚动历史区分 |
| fork a session | 派生新会话 | 与同一会话内的分支区分 |
| branch | 分支 | 同一会话内的路径分叉，Git 语境仍为 Git 分支 |
| resume / continue | 恢复 / 继续 | 两个命令的参数和值分别保留 |
| steering | 引导 | 在当前轮次进行中修改指示 |
| compaction | 上下文压缩 | 汇总旧消息以缩减上下文时的固定译法 |
| approval | 审批 | 操作结果语境可用「批准」或「拒绝」 |
| profile | 配置档案 | 与单独的配置文件区分 |
| workspace / worktree | 工作区 / 工作树 | 后者指 Git 工作树 |
| credentials | 凭据 | 密钥、令牌或 OAuth 授权的统称 |
| magic keywords | 触发关键词 | 界面标签 `Magic Keywords` 和配置名保留 |
| marketplace | 插件市场 | catalog 指插件目录清单，非一定指文件系统目录 |
