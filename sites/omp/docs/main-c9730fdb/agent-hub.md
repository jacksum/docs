# 智能体中心 \{#agent-hub}

智能体中心是用于观察和控制当前会话关联子代理的交互式 TUI。它集成实时名单、各智能体的活动与用量、会话记录访问、引导、恢复和终止控件。主智能体不列在其中，因为它的对话就是当前会话视图。

恢复会话时，中心还会从当前会话的持久化产物中发现已停驻的子代理。顾问会话记录文件显示为只读行。

## 打开中心 \{#open-the-hub}

| 输入 | 行为 |
| --- | --- |
| `Alt+A` | 通过 `app.agents.hub` 打开或关闭智能体中心。即使名单为空也会打开。 |
| `Ctrl+S` | 通过旧版 `app.session.observe` 操作打开或关闭同一中心。 |
| 双击 `←` | 当前会话有可显示的智能体时，从空白的主会话编辑器打开中心。 |

运行 `/hotkeys` 查看当前生效的组合键。在 `~/.omp/agent/keybindings.yml` 中重新映射任一操作：

```yaml
app.agents.hub: Alt+A
app.session.observe: Ctrl+S
```

双击 `←` 手势不是按键绑定操作。焦点位于子代理时，双击 `←` 会返回主会话，而不是打开中心。

## 名单与检查面板 \{#roster-and-inspector}

名单根据会话的智能体注册表和进度事件更新。其自适应行会显示：

- 状态（`running`、`idle`、`parked` 或 `aborted`）、智能体身份、父级和未读 IRC 数量；
- 模型角色、解析后的模型以及距上次活动的时间；
- 分配的任务或当前活动；
- 费用、活跃时间或经过的时长、请求次数、工具调用次数和 token 数。

顶部汇总已度量智能体的状态与用量。按 `t` 在按运行情况排序的平铺名单与父子树之间切换。按 `/` 按 id 或显示名称筛选智能体。

在宽终端上，所选智能体的检查面板显示在名单旁。在窄终端上，按 `Tab` 用检查面板替换名单。检查面板还会显示：

- 当前工具及参数、上次意图和重试状态；
- 可用时显示上下文窗口用量；
- 父子沿袭关系；
- 输出和补丁路径，以及存在时的隔离工作树分支元数据。

指标取决于该智能体可用的进度或持久化用量数据。缺少数据时显示 `usage —`，而不是估计值。

### 名单控件 \{#roster-controls}

| 按键或输入 | 操作 |
| --- | --- |
| `j` / `k`、`↑` / `↓`、滚轮 | 选择智能体。 |
| `Enter` 或单击 | 打开所选智能体。 |
| `t` | 切换平铺视图和父子视图。 |
| `/` | 按 id 或显示名称筛选智能体。 |
| `1` / `2` | 在智能体和活动区域之间切换。 |
| `Tab` | 在窄终端上切换检查面板。 |
| `PageUp` / `PageDown` | 滚动已打开的检查面板。 |
| `r` | 恢复所选的已停驻或已终止智能体。 |
| `x` | 必要时中止正在运行的轮次，然后终止并释放所选智能体。 |
| `Esc` | 先清除生效的筛选，再关闭窄屏检查面板或中心。 |

`parked` 和已终止（`aborted`）的智能体可以恢复：会话记录保存在磁盘上，因此已终止的智能体会以带有完整历史的新实例返回。`x` 立即生效；它会停止智能体，直到有操作恢复它或向它发送消息。

## 活动日志 \{#activity-log}

按 `2` 查看合并的活动日志；按 `1` 返回名单。日志包含响应、工具调用、IRC 消息和生命周期活动。有锚点可用时，`Enter` 会打开所选条目对应智能体的会话记录，并定位到该条目。

- `f` 循环切换全部、错误、响应和工具筛选。
- `s` 在全部智能体、所选智能体及其子树之间循环切换范围。
- `/` 搜索活动日志。
- `Space` 切换是否跟随最新条目；手动选择会暂停跟随。
- `Esc` 先清除搜索，再关闭中心。

## 阅读和引导子代理 \{#read-and-steer-a-subagent}

对于普通本地子代理，按 `Enter` 或单击会将主 TUI 的焦点切换到该智能体的会话，并关闭中心。聚焦已停驻或已终止的智能体会恢复它。此时，会话记录、状态行和编辑器都属于该子代理：

1. 阅读它的实时会话记录和工具活动。
2. 输入消息并按 `Enter`，引导正在运行的轮次，或向空闲智能体发送提示。
3. 通过 `Alt+P`、`/switch`、`Ctrl+P`、`Shift+Tab` 或 `/effort` 更改它的模型或思考级别。这些切换仅作用于该会话，不影响主会话。`/model` 和 `Alt+M` 打开相同的会话级选择器，因为角色分配配置的是主会话。
4. 编辑器为空时按 `Esc`，或双击 `←`，返回主会话。

引导使用常规提示路径，因此消息和响应会写入子代理持久化的会话历史。焦点位于子代理时，`Esc` 会返回主会话，不会中断子代理。

没有可在本地聚焦的会话时，中心会改用全屏会话记录查看器。这包括协作访客和顾问行；顾问会话记录为只读。查看器会增量跟踪基于文件的会话记录，并且仅在所选智能体可接收消息时提供输入行。在此发送消息的语义相同：已停驻或已终止则恢复，运行中则引导，空闲则发送提示。

## 固定跳转列表与单击聚焦 \{#pinned-jump-list-and-click-to-focus}

子代理运行时，编辑器上方固定的 `Subagents` 区块会列出每个存活智能体，包括同步任务调用和分离的后台生成任务。

列表会保持简短：显示几行加一个展开控件（`display.pinnedAgents: collapsed`，默认值）、列出全部（`full`），或完全隐藏（`off`）。启用 `tui.mouse` 时，单击展开控件可在前两种显示方式之间切换。

设置 `display.subagentLivePreview: true` 可在每行下添加第二行，显示该智能体正在做什么：当前工具调用（或两次调用之间最近的一次调用）及其单行详情，以及调用运行超过五秒后的已用时间。默认关闭。

启用 `tui.mouse`，即可直接在主会话中单击实时子代理卡片和跳转列表行，无需先打开中心。单击会聚焦该卡片最近的智能体（跳转列表行则聚焦其对应的具体智能体）；聚焦已停驻智能体会恢复它。鼠标悬停在实时目标上时，目标会先高亮，让你看到单击后会打开什么。

只有当前实时视口中的行可以单击，已移出视口的会话记录行位于终端滚屏历史中，单击无法映射回内容。启用捕获会在启用期间改变终端手势：文本选择改为 Shift+拖动，终端会向 omp 报告滚轮刻度而不是滚动，因此普通滚轮滚动会停止；请用终端的键盘滚屏历史快捷键滚动，或关闭捕获。默认关闭。

## 持久化智能体与顾问 \{#persisted-agents-and-advisors}

为持久化会话打开中心时，会扫描该会话的产物树。历史子代理 JSONL 文件会变成已停驻行；已终止智能体的墓碑标记会使其保持中止状态，直到恢复时移除墓碑。嵌套子代理保留父子沿袭关系。输出和补丁产物附加到相应的检查面板行。

顾问会话记录文件（`__advisor*.jsonl`）作为 `advisor` 类型的行显示在其所属会话下。它们是可观测性记录，不是对等智能体：

- 可以打开并跟踪它们的会话记录；
- 不能向它们发送消息；
- 不能恢复它们；
- 不能终止它们。

协作不会复制顾问行，也不会向访客提供其会话记录；主机也会按 id 拒绝针对顾问的聊天、恢复和终止请求。

## 相关界面 \{#related-surfaces}

智能体中心是面向人的实时会话视图。相关命令与内部 URL 的用途更窄：

`/agents` 是独立的智能体定义和设置中心，不是实时名单。它管理已发现的智能体、启用或禁用状态、模型覆盖、预遍历和顾问选择。

- `/jobs` 打印正在运行和最近已结束的异步工具作业快照。它不能替代各智能体的会话记录或控制视图。`/jobs kill <id>|all` 可从命令行取消正在运行的作业。
- `history://<id>` 为编码智能体提供存活或已停驻子代理的精简会话记录，或保留在磁盘上的会话记录。
- `agent://<id>` 解析子代理已保存的最终输出产物；它不是实时会话记录。在该产物存在之前，已注册智能体会解析为其状态、迄今已提交的 `yield` 载荷及其最新助手文本。
- `write agent://<id>` 可引导普通子代理或继续向其提问；`agent://all` 向可见的存活对等智能体广播（仅主智能体可用；子代理的广播会被拒绝）。向已停驻或已终止的子代理发送消息会恢复它。`read history://` 列出已注册智能体及保留在磁盘上的会话记录，并像 `history://<id>` 查询一样，先刷新调用方根节点的持久化名单。
- `read proc://` 列出后台作业和项目服务；`read proc://<id>` 检查状态和输出，但不消费投递内容。

顾问行被有意排除在面向智能体的对等名单、`history://` 索引和 `agent://` 消息工作流之外。
