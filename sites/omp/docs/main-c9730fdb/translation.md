# 翻译说明

本站翻译 [Oh My Pi 官方仓库的文档](https://github.com/can1357/oh-my-pi/tree/c9730fdb620ce4599dd898691e3e3b56003bfcb5/docs)，固定于提交 [c9730fdb620ce4599dd898691e3e3b56003bfcb5](https://github.com/can1357/oh-my-pi/commit/c9730fdb620ce4599dd898691e3e3b56003bfcb5)。该提交来自 main 分支，不代表某个产品发布 tag，也不是 omp.sh 官网网页的逐页译本。

## 原文与范围

正文范围为固定提交下 docs/ 的全部135篇 Markdown 文档，以及作为导航入口的[官方开发者地图](./development.md)。栏目顺序依据同提交的 Subsystem reference；Extending omp 的参考文档单列为扩展与编程接口，地图未列出的文档归入其他官方文档。重复出现在多个官方分类中的文档只有一份译文。

根 README、其他包的文档和7个非 Markdown 示例源文件不计入上述正文数量；相关引用链接到固定提交原文。翻译说明和入口跳转页属于辅助页，不计入原文覆盖。

## 阅读与使用

本文档为非官方中文译文，仅供学习参考。命令、代码、API、配置键、默认值和文件名保留原文。配置或运行行为应结合所用产品版本核对，不能把本快照视为当前安装版本的保证。原文疑点不在译文中擅自改写。
