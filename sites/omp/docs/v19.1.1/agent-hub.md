# 智能体中心 \{#agent-hub}

智能体中心是一个交互式 TUI，用来查看和控制与当前会话关联的子代理。它集成了实时列表、各智能体的活动与用量、会话记录查看，以及引导、唤醒和终止操作。列表不显示主智能体，因为它的对话已显示在当前会话视图中。

恢复会话时，智能体中心还会在当前会话的持久化产物中发现已停驻的子代理。顾问的会话记录文件显示为只读行。

## 打开智能体中心 \{#open-the-hub}

| 输入 | 行为 |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `Alt+A` | 通过 `app.agents.hub` 打开或关闭智能体中心。列表为空时也能打开。 |
| `Ctrl+S` | 通过旧版的 `app.session.observe` 操作打开或关闭同一个智能体中心。 |
| 连按两次 `←` | 当前会话有智能体可显示时，在主会话的空白编辑器中打开智能体中心。 |

运行 `/hotkeys` 可查看当前生效的按键组合。可在 `~/.omp/agent/keybindings.yml` 中重新绑定这两个操作中的任意一个：

```yaml
app.agents.hub: Alt+A
app.session.observe: Ctrl+S
```

连按两次 `←` 不是可绑定按键的操作。焦点位于子代理时，连按两次 `←` 会返回主会话，不会打开智能体中心。

## 列表和检查面板 \{#roster-and-inspector}

列表根据会话的智能体注册表和进度事件更新。各行会根据空间调整，显示：

- 状态（`running`、`idle`、`parked` 或 `aborted`）、智能体身份、父级和未读 IRC 消息数；
- 模型角色、解析后的模型和距上次活动的时间；
- 分配的任务或当前活动；
- 费用、活跃时间或经过的时长、请求次数、工具调用次数和 token 数。

列表头部汇总有计量数据的智能体的状态和用量。按 `t` 在按运行情况排序的平铺列表和父子树视图之间切换。按 `/` 后，可用 ID 或显示名称筛选智能体。

在较宽的终端中，所选智能体的检查面板显示在列表旁。在较窄的终端中，按 `Tab` 用它替换列表。检查面板还会显示：

- 当前工具及参数、最近一次意图和重试状态；
- 上下文窗口用量（如有数据）；
- 父子层级关系；
- 输出和补丁的路径，以及隔离工作树的分支元数据（如有）。

指标取决于该智能体可用的进度数据或持久化的用量数据。缺失数据时显示 `usage —`，不显示估算值。

### 列表操作 \{#roster-controls}

| 按键或输入 | 操作 |
| --------------------------- | ---------------------------------------------------------------------------- |
| `j` / `k`、`↑` / `↓`、鼠标滚轮 | 选择智能体。 |
| `Enter` 或单击 | 打开所选智能体。 |
| `t` | 在平铺视图和父子树视图之间切换。 |
| `/` | 按 ID 或显示名称筛选智能体。 |
| `1` / `2` | 在“智能体”和“活动”两个区域之间切换。 |
| `Tab` | 在较窄的终端中切换检查面板。 |
| `PageUp` / `PageDown` | 滚动已打开的检查面板。 |
| `r` | 唤醒所选的已停驻或已终止智能体。 |
| `x` | 如有必要，先中止正在运行的轮次，然后终止并释放所选智能体。 |
| `Esc` | 先清除生效的筛选条件，再关闭窄屏下的检查面板或智能体中心。 |

已停驻（`parked`）和已终止（`aborted`）的智能体可以唤醒。会话记录存储在磁盘上，因此已终止的智能体会以新实例恢复，并保留完整历史。`x` 立即生效，智能体会停止，直到被唤醒或收到消息。

## 活动日志 \{#activity-log}

按 `2` 打开汇总活动日志，按 `1` 返回列表。日志包含响应、工具调用、IRC 消息和生命周期活动。有定位锚点时，按 `Enter` 打开所选条目对应的智能体会话记录，并定位到该条目。

- `f` 在“全部”“错误”“响应”和“工具”筛选条件之间循环切换。
- `s` 在所有智能体、所选智能体及其子树三个范围之间循环切换。
- `/` 搜索活动日志。
- `Space` 切换是否跟随最新条目。手动选择条目会暂停跟随。
- `Esc` 先清除搜索，再关闭智能体中心。

## 查看和引导子代理 \{#read-and-steer-a-subagent}

对于普通的本地子代理，按 `Enter` 或单击会将主 TUI 的焦点切换到该智能体的会话，并关闭智能体中心。切换到已停驻或已终止的智能体会唤醒它。此时，会话记录、状态栏和编辑器都属于该子代理：

1. 查看它的实时会话记录和工具活动。
2. 输入消息并按 `Enter`，引导正在运行的轮次，或向空闲的智能体发送提示。
3. 用 `Alt+P`、`/switch`、`Ctrl+P`、`Shift+Tab` 或 `/effort` 更改它的模型或思考级别。这些切换只对当前子代理会话生效，不影响主会话。`/model` 和 `Alt+M` 打开同一个仅对当前子代理会话生效的选择器，因为角色分配配置的是主会话。
4. 在编辑器为空时按 `Esc`，或连按两次 `←`，返回主会话。

引导走普通的提示处理流程，因此消息和响应都会写入子代理的持久化会话历史。焦点位于子代理时，按 `Esc` 会返回主会话，不会中断子代理。

如果没有可获得焦点的本地会话，智能体中心会改用全屏会话记录查看器。这包括 Collab 访客和顾问行。顾问的会话记录是只读的。查看器会增量跟踪文件中的会话记录，仅在所选智能体可接收消息时显示输入行。在这里发送消息与前述操作的行为一致：唤醒已停驻或已终止的智能体，引导正在运行的智能体，或向空闲的智能体发送提示。

## 置顶跳转列表与单击切换焦点 \{#pinned-jump-list-and-click-to-focus}

子代理运行期间，编辑器上方置顶的 `Subagents` 区块会列出所有仍存活的智能体，包括通过同步任务调用和分离式后台启动产生的智能体。

列表默认保持简短：可显示几行和一个展开控件（`display.pinnedAgents: collapsed`，默认值），也可显示全部（`full`）或完全隐藏（`off`）。开启 `tui.mouse` 时，单击展开控件可在折叠和展开两种状态之间切换。

将 `display.subagentLivePreview: true` 设为开启，可在每行下方加一行，显示该智能体当前的工具调用（两次调用之间则显示最近一次调用）及一行详情。调用超过五秒后，还会显示经过的时长。默认关闭。

开启 `tui.mouse` 后，无需先打开智能体中心，即可在主会话中直接单击实时子代理卡片或跳转列表的行。单击卡片会将焦点切换到该卡片最近关联的智能体，单击跳转列表的行则会切换到该行对应的智能体。切换到已停驻的智能体会唤醒它。将指针悬停在实时目标上时，该目标会先高亮，让你知道单击后会打开什么。

只有当前实时视口中的行可单击。已退出实时视口的会话记录行留在终端的回滚缓冲区中，单击无法映射回对应内容。鼠标捕获启用期间，终端手势会改变：选择文本要按住 Shift 再拖动；终端将滚轮事件交给 omp，不再自行滚动，所以直接滚动滚轮无法滚动终端。可使用终端的键盘回滚快捷键，或关闭鼠标捕获。默认关闭。

## 持久化的智能体和顾问 \{#persisted-agents-and-advisors}

为持久化会话打开智能体中心时，智能体中心会扫描该会话的产物树。历史子代理 JSONL 文件显示为已停驻的行。已终止智能体的删除标记会让它保持中止状态，直到唤醒时移除该标记。嵌套子代理保留父子层级关系。输出和补丁产物会附在检查面板的相应行上。

顾问会话记录文件（`__advisor*.jsonl`）会作为 `advisor` 类型的行显示在所属会话下。这些行是用来观察活动的记录，不是对等智能体：

- 可以打开并跟踪它们的会话记录；
- 不能给它们发送消息；
- 不能唤醒它们；
- 不能终止它们。

Collab 不向访客复制顾问行，也不向访客提供其会话记录。共享端也会拒绝按 ID 发送给顾问的聊天、唤醒和终止请求。

## 相关入口 \{#related-surfaces}

智能体中心是供人使用的实时会话视图。相关命令和内部 URL 的用途更窄：

`/agents` 是单独的智能体定义和设置中心，不是实时列表。它用于管理发现的智能体、启用或禁用状态、模型覆盖设置、预遍历和顾问选择。

- `/jobs` 打印正在运行和最近已结束的异步工具任务的快照。它不能代替每个智能体的会话记录或控制视图。`/jobs kill <id>|all` 可在命令行取消正在运行的任务。
- `history://<id>` 向编码智能体提供仍存活或已停驻的子代理的简明会话记录，或磁盘上留存的会话记录。
- `agent://<id>` 解析为子代理保存的最终输出产物，不是实时会话记录。在该产物生成之前，对于已注册的智能体，它会解析为智能体的状态、截至目前提交的 `yield` 载荷及最近的助手文本。
- `write agent://<id>` 用于引导普通子代理或向其发送后续消息；`agent://all` 向可见且仍存活的对等智能体广播（仅主智能体可以广播，子代理的广播请求会被拒绝）。给已停驻或已终止的子代理发送消息会唤醒它。`read history://` 列出已注册的智能体和磁盘上留存的会话记录。和查询 `history://<id>` 一样，它会先刷新调用方根智能体的持久化列表。
- `read proc://` 列出后台任务和项目服务；`read proc://<id>` 查看状态和输出，不会消耗待投递的结果。

面向智能体的对等列表、`history://` 索引和 `agent://` 消息流程都明确排除顾问行。
