# Oh My Pi 中文文档

这是 Oh My Pi [仓库 v19.1.1](https://github.com/can1357/oh-my-pi/tree/31ffee513f27a01bba7d4dfbe12bae239cdc646a) 面向使用者的指南和参考资料的简体中文选译，与 [omp.sh 官网文档](https://omp.sh/docs) 分开维护。译文依据该版本的仓库原文；版本以外的功能变化请查阅上游。

Oh My Pi（`omp`）是一个在终端中运行的编码智能体，以 Pi 为基础，支持工具调用、会话和扩展。
